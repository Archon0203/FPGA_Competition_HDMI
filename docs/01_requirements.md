# 01 · 需求与验收口径（对齐官方评分点）

> 依据：《全国大学生嵌入式芯片与系统设计竞赛'2026 FPGA赛道选题指南-安路科技》选题一

## 1. 官方赛题要点

- **平台**：安路 HX4S20C 开发板，主芯片 **EG4S20BG256**。
- **器件资源**：19,600 LUT / 19,600 DFF；片内集成 SDRAM **2M×32bit（≈8MB）**；
  64 块 9Kb ERAM + 16 块 32Kb；4 个 PLL；16 路全局时钟；最多 193 个用户 IO。
- **板载**：4 按键、4 拨码、蜂鸣器、8 位数码管、8 组双色 LED、4 LED、USB-UART、千兆网、
  QSPI Flash 16MB、SPI Flash 64MB、TF 卡槽、双 HDMI 输出、12 位 VGA、2×40Pin 扩展 IO、50MHz 有源时钟。
- **任务**：以音视频融合的多媒体应用为方向，自主设计并实现一个**具有明确应用场景的多媒体展示系统**，
  体现 FPGA 并行处理、实时控制、低延迟显示、音画同步、多源信息融合。
- **硬性红线**：作品中的算法、控制逻辑、数据处理流程必须在 FPGA 中自主编程实现；
  **不得使用外部处理器（MCU/CPU）**（无论用于辅助控制还是算法预处理）。允许用多块同款 FPGA 做主从。

## 2. 官方评分标准（我方逐条映射为验收口径）

| 官方评分项 | 我方验收口径（可测） | 优先级 |
|---|---|---|
| **基础① 核心功能完整性** | SD/TF 读多张 BMP + `.vseq` 短视频片段 → SDRAM 帧缓存 → HDMI 显示；按键手动切图、自动轮播；播放/暂停 | 必做 |
| **基础② 显示稳定性与鲁棒性** | 连续运行 ≥2h；反复快速切图/切片段无花屏、无闪烁、无撕裂；信号稳定无掉线 | 必做 |
| **基础③ 基础音频输出** | HDMI 音频测试音 / 背景音 / 应急提示音输出正常 | 必做 |
| **基础④ 系统工程规范性** | 模块化 + 流水线划分；时钟域/CDC 标注；IO/时序约束齐全；注释与文档规范 | 必做 |
| **扩展① 图层叠加与字幕** | 叠加动态文字（时间戳/标语），多图层混合与平滑滚动 | 加分（高优先） |
| **扩展② 图片切换与转场** | 轮播时淡入淡出/滑动过渡，切换画面连续 | 加分（中，用于图片） |
| **扩展③ 图片自适应缩放** | 支持不同分辨率图片读取并缩放到输出分辨率；短视频帧放大到 640×480 | 加分（高优先） |
| **扩展④ 实时调节与 OSD 叠加** | 拨码/按键调亮度、对比度等，画面显示参数变化 | 加分（高优先） |
| **扩展⑤ 音频可视化** | 结合音频数据生成频谱/波形叠加画面 | 加分（低优先/看时间，建议振幅条/简易频谱） |

## 3. 我们的应用场景（差异化卖点）

**「校园/园区信息发布与应急广播终端」**：多张公告/警示图片 + 宣传短视频片段按设定轮播，
叠加当前时间与滚动标语，紧急时可按键切换到"应急信息页/应急视频"并蜂鸣提醒；
管理员可按键/拨码调整显示亮度、对比度与转场效果。该场景可覆盖基础四项 + 扩展①②③④⑤。

## 4. 自备设备（评选现场用）

需自备其一：
- 支持 HDMI 音视频输入的显示 + 声音播放设备（电视 / 带喇叭显示器）；
- 或 HDMI 显示器 + 外接音箱；
- 或 HDMI 转 VGA/音频转接器 + VGA 显示器 + 音箱。

建议同时备一个 **HDMI 转 VGA** 转接器，防止现场显示器 HDMI 兼容差异导致"黑屏事故"。

## 5. 视频口径说明（重要）

> 本赛题是"多媒体/图片 + 短视频片段"显示系统。**EG4S20 无视频硬解码器，不能解码 H.264/MP4 压缩视频**。
> 我们的"视频"采用 **PC 端离线转帧 → 原始 YCbCr 帧序列(`.vseq`) → FPGA 流式/预载循环播放** 的方式实现，
> 全部读帧、缓存、色彩空间转换、缩放、TMDS 编码均在 FPGA 内完成。具体见 `docs/06` 与 `docs/08`。
