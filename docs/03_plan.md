## P3 · 扩展项（09-29 ~ 10-12）
优先做性价比高 + 风险低 + 好演示：
- [ ] **扩展④ 实时调节 + OSD 叠加**（亮度/对比度，画面显示参数）——纯 RTL，最稳。
- [ ] **扩展① 图层叠加与字幕**（当前时间戳 + 滚动标语，字库 ROM + 行缓存）。
