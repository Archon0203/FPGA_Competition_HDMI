# 07 · 明确使用场景：“智慧校园/园区信息发布与应急广播终端”

> 一个可讲、可演示、可被评委理解的具体场景，它把图片、视频、字幕、音频、交互串联起来，并覆盖全部评分点。

## 1. 场景描述

在校园/园区大厅、教学楼或展馆部署一块“信息发布与应急广播终端”，用 **EG4S20 FPGA 单板**完成全部显示、播放、音画同步与交互，**不含外部 CPU**：

### 常规模式（日常）
- **内容编排**：按计划轮播——政策/公告**图片**（BMP）、活动宣传**短片**（`.vseq` 视频片段）、当前**时间**、滚动**标语**。
- **背景音**：FPGA 合成轻量背景音，或播放预采样 PCM，做到音画同步。
- **用户交互**：按键——上/下一张、播放/暂停、切换播放源（图片/视频）；拨码——调**亮度/对比度**、切换**转场特效**、开关**OSD**。
- **状态显示**：数码管显示当前图号/播放状态/参数档位；双色 LED 指示播放/暂停。

### 应急模式（亮点）
- 拨码/按键一键进入**应急广播**：立即切到“应急信息页/应急视频 + 大字警告 + 蜂鸣告警 + 应急提示音”。
- 强调 FPGA 的**低延迟/确定性**：应急切入必须毫秒级、无卡顿，这是 FPGA 方案相对通用处理器的优势叙事。

## 2. 该场景如何覆盖评分点

| 评分点 | 场景如何体现 |
|---|---|
| 基础①核心功能 | 图片/视频读取→SDRAM→HDMI 显示 + 切图/轮播/播放暂停 |
| 基础②显示稳定 | ≥2h 连续运行、反复切换无花屏/撕裂（双/三缓冲） |
| 基础③基础音频 | 背景音/测试音/应急提示音，经 HDMI 输出 |
| 基础④工程规范 | 模块化/流水线/时钟域约束/文档 |
| 扩展①图层字幕 | 时间戳 + 滚动标语叠加 |
| 扩展②转场 | 图片/视频切换淡入淡出/滑动 |
| 扩展③缩放 | 不同分辨率图片 + 320×240 视频放大到 640×480 |
| 扩展④实时调节+OSD | 拨码调亮度/对比度，画面显示参数 |
| 扩展⑤音频可视化 | 音频频谱/波形叠加画面 |

## 3. 差异化卖点（评委视角）

- **多源信息融合**：图片 + 视频 + 时间 + 标语 + 音频，在单板融合成“信息发布终端”。
- **确定性/低延迟**：应急切换毫秒级；FPGA 无操作系统抖动。
- **无 CPU 依赖**：全部在 FPGA 内完成，契合赛题红线与“国产 FPGA 自主编程”立意。
- **工具链完整**：离线转帧 `.vseq`、字库、SD 制作脚本齐全，体现工程完整度。

## 4. 一句话口径（答辩用）

“我们用一块 EG4S20 FPGA，把校园信息发布终端做成了：图片、短片、时间、标语、背景音多路融合，可实时调参、可一键应急广播，全程无外部处理器。”

> ⚠️ 口径红线：说“短视频片段/图片/动画”，**不说“实时视频解码/MP4 播放”**；说“GPU/CPU 之外，用 FPGA 做确定性显示与管理”。
